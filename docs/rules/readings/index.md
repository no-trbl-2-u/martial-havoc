# Readings

A reading is a decision the rulebook or the adventure leaves to the player,
recorded with the inventory's inferred answer. Each row keeps the
inventory's ids: `A-nn` for the ambiguity, `I-nn` for the reading (rows
without an `I-nn` have no defensible inference from the sources alone),
`D-nn` for a discrepancy against the operator's Spark. Every inferred item
is marked `(inferred)` as the inventory marks it. Nothing here is a rule;
the rules are in [Rules](../index.md). An engine that adopts a reading
labels the behaviour `reading`, not `rule`.
